# 多模型 Wiki 工作台验收清单

## 自动化基线

- [x] 四家供应商共用 `ModelProvider` 契约，密钥按供应商隔离保存在凭据库抽象中。
- [x] 会话、成员、消息、事件与资料关联可写入 SQLite，并可关闭后重开。
- [x] 独立发言决策、公开理由、全员沉默、点名、故障隔离、用户停止与 12 条上限有调度器测试。
- [x] Markdown、TXT、DOCX、文本 PDF、图片元数据和网页快照导入有不可变性与失败路径测试。
- [x] Wiki 原子写入、索引、日志、复核状态与安全回退有服务测试。
- [x] 端到端测试覆盖两个模型、Markdown 附件、一个回复、一个沉默、Wiki 修订、待复核、回退及 SQLite 重开恢复。
- [x] 端到端测试递归扫描测试工作区，确认哨兵 API Key 未进入 SQLite、`raw/`、Wiki 或日志。
- [x] 前端组件测试覆盖公开决策、停止讨论、密钥不回填和三种复核操作。

## 桌面人工验收

### 供应商与密钥

- [ ] 分别保存并校验 OpenAI、Anthropic、Google Gemini、DeepSeek 的有效 API Key。
- [ ] 输入无效密钥时显示中文可操作错误，关闭重开设置后不回显密钥原文。
- [ ] 删除密钥后显示未配置；未配置成员不会阻断其他已配置模型。
- [ ] 断网、超时、额度不足时对应模型显示故障，其他模型仍可完成本轮。

### 自然群聊

- [ ] 新建会话并添加至少两个不同供应商、不同角色的模型。
- [ ] 发送消息后可看到每个模型的“准备回复”或“保持沉默”及公开理由。
- [ ] 多个模型同时希望发言时按优先级稳定排队，且同一模型不连续发言。
- [ ] 全员沉默时本轮自动结束；连续回复达到 12 条时自动停止。
- [ ] 点击停止后本轮终止，随后发送新消息可继续讨论。
- [ ] 点名一个模型时仅该模型参与本次决策。

### 资料与 Wiki

- [ ] 导入 Markdown、TXT、DOCX、文本 PDF、图片和网页，界面显示提取成功或明确失败原因。
- [ ] 原始文件未被修改，工作区 `raw/` 中存在内容哈希命名的副本或网页快照。
- [ ] 附加资料后发起讨论，模型回复能使用资料内容，讨论结束出现会话 Wiki 页面。
- [ ] `wiki/index.md` 包含页面链接，`wiki/log.md` 追加本次修订记录。
- [ ] 待复核项可展开查看修改前后内容，并可接受、标记错误或回退。
- [ ] 回退后 Wiki 页面恢复上一版本；已有后续修订时拒绝不安全回退。

### 持久化与界面

- [ ] 关闭并重开桌面应用后，会话、成员、消息、资料、Wiki 和复核状态均恢复。
- [ ] 在 1280×800 和最小 960×640 窗口下三栏无重叠，消息区和侧栏可独立滚动。
- [ ] 使用键盘遍历会话、标签、弹窗、输入框与操作按钮，焦点可见且顺序合理。
- [ ] 发布构建启动后没有控制台错误，文件选择、凭据库和 SQLite 均使用本地桌面能力。
